Principles
Overview on the canvas, detail in the panelCards stay small and readable. Settings open in one side panel, never a modal.
Never colour aloneEvery state has an icon and a word as well as a colour.
Problems show before you runMissing keys and broken references appear on the card, not in a failed run.
Runs live on the nodesStatus, item counts and the failing message sit where you were already looking.
